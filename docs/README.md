# Documentation

Everything beyond the [project README](../README.md) lives here, in one of three homes:

| Home | Holds |
|---|---|
| [architecture/](architecture/README.md) | How the library is built: architecture, major abstractions, design decisions and their dated records |
| [guides/](guides/README.md) | Task-oriented guides for using and extending the library |
| [reference/](reference/README.md) | Stable configuration and API reference, held to the code by tests |

An image a page needs goes in `images/`, which does not exist yet: the first image creates it. Why the documentation is shaped this way is recorded in
[the documentation-architecture decision](architecture/decisions/2026-09-27-documentation-architecture.md).
