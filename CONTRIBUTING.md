# Contributing

Thank you for helping. Spark Quick Start is a Public Preview / Beta maintained by Iteration
Insights. Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md).

## How to take part

The maintainers make every change themselves, so this repository does not accept pull requests.
What helps most is a clear report:

- **A bug:** open an Issue with the bug form. Give the commit you run, the platform (Microsoft
  Fabric, Azure Databricks or local, classic or serverless), what you expected and what happened,
  and the smallest load context that shows it.
- **An idea or an enhancement:** open an Issue with the feature form, and say what you are trying
  to do rather than only the change you have in mind.
- **A question:** start a GitHub Discussion. The [documentation](docs/README.md) may already
  answer it.
- **A security vulnerability:** never in public; follow [SECURITY.md](SECURITY.md).

Describe the problem in words and with a load context; please do not paste a patch.

## What happens next

A maintainer reads each Issue and Discussion. Support is best effort, with no response time
promised and no commercial SLA. A change the maintainers take on is made in their own repository
and arrives here in a later publication, listed in [CHANGELOG.md](CHANGELOG.md); the Issue is then
closed with a note saying where. For architecture, implementation or production help,
[contact Iteration Insights](https://iterationinsights.com/contact-us/).
