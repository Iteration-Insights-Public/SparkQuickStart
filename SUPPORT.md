# Support

Spark Quick Start is open-source software provided by Iteration Insights as a Public Preview /
Beta.

- **Questions:** start with the [documentation](docs/README.md); if it does not answer, start a
  GitHub Discussion.
- **Bugs and enhancement requests:** open a GitHub Issue with its form, as
  [CONTRIBUTING.md](CONTRIBUTING.md) describes.
- **Security vulnerabilities:** never in public; see [SECURITY.md](SECURITY.md).

Community support is best effort, and the project has no commercial support SLA.

## Commercial help

Organizations that need architecture, implementation, customization or production support can
engage Iteration Insights separately: [contact us](https://iterationinsights.com/contact-us/).
