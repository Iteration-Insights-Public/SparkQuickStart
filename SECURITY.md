# Security policy

## Supported versions

Spark Quick Start is a Public Preview / Beta. Security fixes go into the latest 0.x release only;
upgrade to it before reporting.

## Reporting a vulnerability

Report a vulnerability privately, through this repository's **Security** tab →
**Report a vulnerability** (GitHub private vulnerability reporting). Do not open a public issue,
pull request or discussion for it.

Include what you can: the affected version, the platform (Microsoft Fabric, Azure Databricks or
local), the steps or load context that reproduce it, and the impact you see.

## What to expect

Reports are handled on a best-effort basis by the maintainers at Iteration Insights; the project
has no support SLA. We acknowledge a report when we have read it, keep you informed in the private
advisory, and credit you when a fix is published, unless you ask us not to.
